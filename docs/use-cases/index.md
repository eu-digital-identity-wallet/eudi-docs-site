# Use Cases

The EUDI Wallet's development is guided by real-world use cases defined in the [Architecture and Reference Framework (ARF)](https://eudi.dev/latest/architecture-and-reference-framework-main/){:target="_blank"}. Each use case shows how the reusable components of the reference implementation fit together to deliver a complete, interoperable flow — from issuing an attestation to presenting it to a verifier.

This section provides the technical guidance for the first of these use cases.

## Mobile Driving Licence (mDL)

Issue, hold and present a driving licence as an electronic attestation of attributes, in line with ISO/IEC 18013-5 and the 4th Driving Licence Directive. The guides cover the Wallet Provider, mDL Issuer and mDL Verifier perspectives, with architecture, specifications and step-by-step workflows.
